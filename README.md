# ✦ Página de Login

### Uma interface simples para praticar formulários e estilização.ᐟ

Projeto colaborativo desenvolvido durante os estudos de **Front-end** com o objetivo de criar e estilizar uma página de login utilizando HTML e CSS.

<br>

<img src="https://skillicons.dev/icons?i=html,css"/>

<br>

## ✦ Sobre o projeto

A proposta foi desenvolver uma interface de login contendo os principais elementos de um formulário, trabalhando a organização dos campos e a estilização da página.

A interface conta com campos de e-mail e senha, opção de lembrar o usuário, recuperação de senha e acesso ao cadastro.

## ✦ O que praticamos

- Estruturação de formulários com HTML
- Inputs de e-mail e senha
- Labels e placeholders
- Checkbox
- Botões e links
- Estilização com CSS
- Flexbox
- Pseudo-classes como `:hover` e `:focus`
- Bordas, sombras e espaçamentos
- Trabalho colaborativo com Git e GitHub
